GPC Wallet Support

使用前须知

GPC Wallet 是非托管钱包。我们不会保存您的助记词或私钥，也无法替您恢复丢失的助记词、撤销已确认的区块链交易或冻结链上资产。

常见问题

如何恢复资产钱包？
请在“钱包 → 管理 → 导入钱包”中使用您自行备份的助记词或私钥恢复。

为什么交易长时间未确认？
请检查 BNB Smart Chain 网络状态、RPC 设置、Gas 余额及交易哈希。链上拥堵时确认可能延迟。

如何清除消息或缓存？
可在消息列表左滑删除本地会话数据，或在“我的 → 设置 → 清除缓存”中统一处理。

如何申请删除服务端资料？
请通过 App 内 GPC 官方公众号提交请求，并使用对应身份钱包完成所有权验证。链上公开记录无法删除。

提交问题

您可以在 GitHub 支持工单中描述 App 版本、设备系统、复现步骤和错误提示。请勿提交助记词、私钥、支付密码、完整签名或其他敏感信息。
